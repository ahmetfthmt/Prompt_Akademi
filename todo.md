# Teslim Takibi

## GitHub Hazırlığı

- [x] GitHub için depo belgelerini, lisansı ve doğrulama iş akışını ekle.
- [x] Hassas veya üretilen dosyaların depoya girmediğini kontrol et.
- [x] GitHub'a hazır klasör yapısını tek bir ZIP arşivinde paketle ve doğrula.
- [x] ZIP arşivini kullanıcıya teslim et.

## Ders İçeriği Geliştirme

- [x] Beş modülün her biri için ayrıntılı ders metni, örnek ve karşı örnek akışını oluştur.
- [x] Ders sayfalarına görsel açıklamalar, hareketli süreç diyagramları ve mini uygulamalar ekle.
- [x] Ders kartlarını gerçek ders sayfalarına bağla ve ilerleme akışını koru.
- [x] Ders sayfalarını, etkileşimlerini ve üretim derlemesini doğrula.

- [x] Proje klasörünü hiyerarşik yapısı korunacak biçimde ZIP arşivine ekle.
- [x] Arşivde ana proje klasörü, kaynak kodlar ve yapılandırma dosyalarının yer aldığını doğrula.
- [x] ZIP dosyasını kullanıcıya ek olarak teslim et.
